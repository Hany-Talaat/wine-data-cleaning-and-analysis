# Wine Data Cleaning and Analysis

## Overview

A Python and Pandas project focused on cleaning and analyzing a wine dataset.

The project demonstrates practical data preprocessing techniques and exploratory analysis using Python.

## Technologies

- Python
- Pandas
- Jupyter Notebook

## Data Cleaning

The project includes:

- Handling missing numerical values
- Filling missing categorical values
- Removing records with missing wine varieties
- Cleaning Twitter handles
- Checking remaining missing values

## Data Analysis

The analysis answers questions such as:

1. Which countries have the highest average wine ratings?
2. How many wines scored 95+ points and cost $20 or less?
3. What are the five most frequently reviewed wine varieties?
4. How does average price vary by score?
5. Which wineries have the most reviews?
